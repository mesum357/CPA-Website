# Taxima CPA Website

Frontend for [Taxima CPA](https://www.taximacpa.com), built from the provided Figma/design comps.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- GSAP (scroll reveals)

## Develop

```bash
cd web
npm install
npm run dev
```

## Build

```bash
cd web
npm run build
npm run preview
```
